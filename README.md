# Broadcast Storm LIVE｜全班即時互動教學遊戲

一個適合企業電腦網路課堂報告的多人大螢幕互動網站。**零外部 Node.js 套件**，Node.js 18+ 即可執行。

## 玩法

- 主持人按「建立教室」，取得 6 位教室代碼、專用控制台與 QR Code。
- 同學掃描 QR Code，輸入暱稱，按「發送廣播封包」。
- 大螢幕即時顯示人數、廣播事件、模擬轉送數和負載。
- 主持人「接上 Loop」，此時 **STP 預設開啟**，封包不會持續循環。
- 主持人「停用 STP」，再次請同學發送廣播，觀察模擬流量上升。
- 最後「啟用 STP」，對比負載下降，帶入正式 STP/RSTP 講解。

## 本機執行（Windows）

1. 安裝 Node.js 18 或更新版本（如果已安裝可省略）。
2. 解壓縮整個專案，進入 `broadcast-storm-live` 資料夾。
3. 在檔案總管網址列輸入 `cmd`，按 Enter，然後執行：

   ```bash
   npm start
   ```

4. 電腦瀏覽器開啟 http://localhost:3000 ，按「我是主持人」。
5. 要在同一台電腦測試學生畫面：複製主持人顯示的加入網址並在無痕視窗開啟。

**注意**： `localhost` 只限同一台電腦。學生的手機要加入，必須部署到公開的 HTTPS 網址，或在同一個區域網路改用電腦的 LAN IP 並開放防火牆連入。

## 發布到網路（推薦：Render Node Web Service）

1. 註冊或登入 GitHub，建立一個**公開或私有 Repository**，把此專案的整個檔案上傳到儲存庫根目錄。
2. 登入 https://dashboard.render.com/ ，建立 **New → Web Service**，連結該 GitHub Repository。
3. 選擇 **Node** 環境（若提供），設定：
   - Build Command：`npm install`
   - Start Command：`npm start`
   - Port：程式自動讀取 Render 的 `PORT` 環境變數。
4. 等待部署成功，開啟平台提供的 HTTPS 網址。
5. 按「我是主持人」，此時產生的 QR Code 將指向你的公開 HTTPS 網址。同學用不同的手機網路也能加入。

可能有免費與付費方案、閒置休眠及其他平台限制，部署前請依當時 Render 的服務條款與定價確認。**正式上台前，先讓 3–5 台手機一起測試**。

## 預估示範時間：4 分鐘

| 時間 | 主持人操作 | 學生操作 |
|---|---|---|
| 0:00–0:40 | 出示 QR Code | 掃碼加入 |
| 0:40–1:20 | 維持正常拓樸 | 各按 1 次發送廣播 |
| 1:20–2:00 | 接上 Loop，仍保留 STP | 再按 1 次，觀察網路正常 |
| 2:00–3:00 | 停用 STP | 再按 1 次，觀察流量上升 |
| 3:00–4:00 | 重新啟用 STP，講解差異 | 觀察負載回落 |

## 模擬邏輯（請務必在報告中說明）

這是**教學遊戲，並非 Cisco Packet Tracer、真實交換器或網路封包分析工具**。

- 同學按下按鈕，只會向網站送一個 HTTPS 事件，不會從手機發送真正的乙太網路廣播。
- 伺服器把這個事件視為一個模擬 ARP Request，並產生簡化的負載指數。
- Loop 未形成、或 STP 防護開啟時，模擬負載快速下降。
- Loop 存在且 STP 關閉時，模擬封包持續轉送；為了展示多重路徑可能產生的封包複本，模型設定活躍負載每秒乘上 1.19、再加上固定增量，並限制在 10,000；這是**遊戲設計參數而非物理定律或實際量測數據**。
- 模擬中的「轉送數」不代表 Packet Tracer 的封包統計；真實流量及丟包率須由獨立實驗測量。
- **三角形實體拓樸不等於一定會發生廣播風暴**。當 STP 正常運作時，形成迴圈的備援路徑會被阻擋。

## 安全與限制

- 本專案只做**邏輯模擬**，不會真的製造網路風暴。
- 不要在學校或企業的真實交換器上停用 STP 來做實驗。
- 主持人網址內含 `key`，請勿公開分享主持人網址或投影片截圖中的控制金鑰；只分享 QR Code 與學生加入連結。
- 課堂房間與資料儲存在伺服器記憶體，重啟伺服器會清空，建立後最長 12 小時自動刪除。
- 目前以單台 Web Service 執行；多台負載平衡、永久紀錄、嚴格人數驗證等功能未建置。
- QR 圖片透過第三方 `api.qrserver.com` 動態產生，若該服務無法使用，可直接複製學生加入連結發給大家。
